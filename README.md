# Soyo bot

Render sozlamalari:
- Build Command: npm install
- Start Command: npm start

Maxfiy sozlamalar (Environment):
- BOT_TOKEN: BotFather bergan token
- DATABASE_URL: Neon connection string
- WEBHOOK_SECRET: o'zing o'ylagan uzun tasodifiy matn (harf va raqam)
- OWNER_IDS: do'kon egasining Telegram ID si (bir nechta bo'lsa vergul bilan: 123,456)
- CARD_NUMBER: to'lov uchun karta raqami
- CARD_HOLDER: karta egasining ismi (ixtiyoriy)
- DELIVERY_FEE: yetkazib berish narxi so'mda, masalan 25000 (bo'lmasa 0)
